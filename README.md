# 💰 Expense Tracker (Controle Financeiro)

Aplicação web de controle financeiro desenvolvida em React.  
Permite adicionar entradas e despesas, calcular saldo total e armazenar dados no navegador.

---

## 🚀 Funcionalidades

- ✅ Adicionar receitas (income)
- ❌ Adicionar despesas (expense)
- 📊 Exibir saldo total automaticamente
- 💾 Persistência de dados com LocalStorage
- 🧾 Listagem de transações
- 🔄 Atualização em tempo real

---

## 💡 Como funciona

O sistema permite que o usuário registre transações financeiras classificadas como entrada ou saída.

- As entradas aumentam o saldo
- As despesas diminuem o saldo
- O cálculo é feito automaticamente com base na lista de transações

Os dados são armazenados no **LocalStorage**, garantindo que não sejam perdidos ao atualizar a página.
